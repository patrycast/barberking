# Barberking Barbershop

React + Vite + styled-components.

```bash
pnpm install
pnpm dev      # desarrollo
pnpm build    # producción
```

## Cargar imágenes
Copiá las fotos en `public/img/` y completá la lista `GALLERY` en `src/App.jsx`
(`src: "/img/corte1.jpg"`). Cada `<img src="">` vacío muestra un recuadro de reserva.
